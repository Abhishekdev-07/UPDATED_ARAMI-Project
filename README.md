Project Ivory: Historical News Summarizer
Ivory is an AI-powered tool designed to bridge the gap between historical archives and modern consumption. Building on the architecture of the ARAMI browser extension, Ivory fetches historical newspaper data via the Library of Congress (Chronicling America) API and transforms dense, archaic text into concise, digestible summaries using NLP.

Features
Historical Integration: Connects directly to the Library of Congress API to access digitized newspaper records.

AI Summarization: Leverages transformer-based models (like BART) to distill long-form historical reporting into key bullet points.

Time-Travel Discovery: Allows users to explore headlines and news cycles from specific eras in history.

Contextual Awareness: Specifically tuned to handle the linguistic nuances of older English text.

Technical Stack
Language: Python

Summarization Engine: Hugging Face Transformers (BART-large-cnn)

API: Chronicling America API (Library of Congress)
